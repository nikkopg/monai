## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /categories REST | untrusted names/colors/icons/parent_ids cross into SQL and the DB |
| category mutation → LLM engine cache | stale singleton serves deleted/renamed categories (Pitfall 5) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-08 | Elevation of Privilege | POST/PUT/DELETE /categories | high | mitigate | Depends(require_api_key) on every mutating route, matching /accounts (Task 2) |
| T-11-09 | Tampering | category name in SQL (rename/merge/count queries) | high | mitigate | SQLAlchemy text() with bound parameters only; Pydantic schemas validate shape (Task 2) |
| T-11-10 | Tampering (integrity) | orphaned transactions or subcategories on delete | high | mitigate | Block-or-reassign guard checks tx count AND child count; FK without ondelete backstops at DB level (Task 1 tests, Task 2) |
| T-11-11 | Repudiation | untracked category mutations | medium | mitigate | One AuditLog row per apply_* call (writes.py module contract) |
| T-11-12 | Information Disclosure | stale LLM cache after mutation | medium | mitigate | reset_engine() after every category mutation commit (Pitfall 5, acceptance criterion) |
| T-11-SC | Tampering | npm/pip/cargo installs | low | mitigate | No packages installed in this plan |
</threat_model>
