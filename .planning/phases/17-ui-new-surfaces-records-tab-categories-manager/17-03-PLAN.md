<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web client → REST API | Untrusted filter params + bulk id arrays cross here; the real destructive surface is bulk-delete |
| REST API → PostgreSQL | Parameterized SQLAlchemy only; write routes api-key-gated and audit-logged |
| REST API → agent/MCP surface | New reads/writes must NOT leak onto the MCP read-only tool surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-04 | Tampering | SQL injection via `q`/`category`/date params | high | mitigate | All params bound through SQLAlchemy `.filter()` / `.ilike()` — never string-concatenated into text(); FastAPI type-coerces int/float/bool params (422 on malformed) |
| T-17-05 | Tampering / Info-disclosure | bulk-delete/recategorize accepting arbitrary or non-existent ids | high | mitigate | Each id validated via db.get(...) is None → append to skipped[] (no raw 500 / IntegrityError leak, per apply-fk-integrityerror-not-422); pair cascade scoped to the exact sibling (transfer_pair_id == X AND id != tx_id) so no unintended row is removed |
| T-17-06 | Denial of Service (self-inflicted data loss) | mass bulk-delete blast radius | high | mitigate | Web-app-only (api-key-gated, off MCP); UI gates behind ConfirmDialog showing the count (Plan 17-04); reject an over-cap ids array (>500, matching the per-request row cap) with 422 at the endpoint |
| T-17-07 | Elevation of Privilege | new reads/bulk writes leaking onto the agent/MCP tool surface | high | mitigate | Do not add any Phase 17 endpoint to backend/tools.py TOOLS / READ_TOOL_NAMES; acceptance criterion greps tools.py shows zero new entries (D-05) |
| T-17-08 | Repudiation | bulk mutation not auditable | medium | mitigate | One AuditLog row per entity (delete + recategorize), before-dict copied verbatim with str(tx.amount) so JSONB serialization never breaks (auditlog-decimal-json-gotcha) |

No package installs this phase (pure FastAPI/SQLAlchemy composition) — no supply-chain (T-*-SC) threat applies.
</threat_model>
